# 系统字典设计

## 1. 目标与范围

本设计用于替代原“平台字典”方案，落地为统一的 `系统字典` 能力。

第一版系统字典覆盖以下 3 类业务字典：

- 平台
- 充电站状态
- 充电桩状态

本次设计目标是先完成统一数据模型与后续页面交互边界定义，作为里程碑 B 后续任务的依据。

## 2. 为什么采用系统字典

当前业务中，平台数量较少、变化频率不高，若只为平台单独建设一套字典模块，复用价值有限。

因此本期改为统一建设 `系统字典`：

- 把平台、充电站状态、充电桩状态纳入同一套管理能力
- 提前建立统一的字典数据源，避免后续不同页面各自维护一套枚举或配置
- 为后续扩展更多字典类型预留结构，但本期不把范围扩大到“任意新增字典类型”

## 3. 总体方案

### 3.1 方案选择

本期采用：

- `字典类型表 + 字典项表`

不采用：

- 仅一张字典项表的轻量模型
- 每类字典单独一张业务表的分散模型

选择该方案的原因：

- 结构语义清晰，类型与项目职责分离
- 第一版只内置 3 类，但数据库结构天然支持后续扩展
- 避免未来继续新增字典类型时再次重构表结构

### 3.2 页面边界

- 页面菜单口径调整为：`系统字典`
- 页面只允许系统管理员访问
- 页面暂不开放“新增字典类型”
- 页面只管理预置的 3 类字典项

## 4. 字典范围

### 4.1 第一版内置字典类型

- `PLATFORM`：平台
- `STATION_STATUS`：充电站状态
- `PILE_STATUS`：充电桩状态

### 4.2 类型扩展策略

- 数据库允许后续继续增加新的字典类型
- 本期页面不提供“新增字典类型”功能
- 如果未来需要新增字典类型，可通过初始化脚本或后续功能迭代接入

## 5. 数据模型

### 5.1 字典类型表

建议表名：`sys_dict_type`

建议字段：

- 主键ID
- 类型编码 `type_code`
- 类型名称 `type_name`
- 类型状态 `type_status`
- 排序 `sort_order`
- 创建时间
- 更新时间

规则建议：

- `type_code` 全局唯一
- `type_name` 全局唯一
- `type_status` 支持 `ENABLED / DISABLED`
- `sort_order` 用于页面左侧类型顺序展示

### 5.2 字典项表

建议表名：`sys_dict_item`

建议字段：

- 主键ID
- 字典类型ID `type_id`
- 项目编码 `item_code`
- 项目名称 `item_name`
- 项目状态 `item_status`
- 排序 `sort_order`
- 创建时间
- 更新时间

规则建议：

- 同一 `type_id` 下，`item_code` 唯一
- 同一 `type_id` 下，`item_name` 唯一
- `item_status` 支持 `ENABLED / DISABLED`
- `sort_order` 用于同类型下的显示顺序

## 6. 第一版数据要求

### 6.1 字典类型初始化

系统初始化时至少应写入以下类型：

- `PLATFORM`
- `STATION_STATUS`
- `PILE_STATUS`

### 6.2 字典项初始化口径

平台类字典项：

- 初始数据可为空，由系统管理员后续维护

充电站状态字典项：

- 建议初始化：`签合同`、`建设中`、`运营中`、`运营异常`、`停用`

充电桩状态字典项：

- 建议初始化：`运营中`、`运营异常`、`停用`

说明：

- 当前业务对充电站状态与充电桩状态没有强业务约束，因此允许系统管理员维护这些状态字典项
- 但后续若业务规则增强，需要重新评估是否继续允许状态类字典自由增删改

## 7. 页面设计方向

### 7.1 页面结构

系统字典页建议采用：

- 左侧：字典类型导航区
- 右侧：当前字典类型对应的字典项列表与操作区

左侧固定展示：

- 平台
- 充电站状态
- 充电桩状态

### 7.2 右侧列表能力

右侧字典项区域支持：

- 查看列表
- 新增字典项
- 编辑字典项
- 启用 / 停用字典项

列表字段建议：

- 名称
- 编码
- 状态
- 排序
- 更新时间
- 操作

### 7.3 表单字段

字典项表单统一使用：

- 名称
- 编码
- 状态
- 排序

约束：

- 名称必填
- 编码必填
- 状态必填
- 排序必填

## 8. 业务复用关系

### 8.1 平台

- 充电站新增/编辑表单中的“所在平台”来自 `PLATFORM`
- 充电站列表中的平台筛选条件来自 `PLATFORM`

### 8.2 充电站状态

- 充电站列表筛选中的状态选项来自 `STATION_STATUS`
- 充电站详情页中的状态展示与切换目标来自 `STATION_STATUS`

### 8.3 充电桩状态

- 充电桩分区中的状态展示与切换目标来自 `PILE_STATUS`

## 9. 权限与操作边界

- 仅系统管理员可进入系统字典页面
- 业务管理员不可见系统字典菜单
- 业务管理员不可维护任何字典项
- 本期不开放删除能力，采用 `启用 / 停用` 管理字典项

## 10. 非本任务范围

以下内容不在当前设计对应任务内：

- 页面开放新增字典类型
- 字典项批量导入导出
- 多级字典
- 字典项备注、颜色、扩展JSON等附加属性
- 与外部平台 API 参数配置的合并管理

## 11. 验收口径

- 系统存在统一的 `系统字典` 数据模型，而非单独的平台字典模型
- 第一版系统字典至少覆盖：平台、充电站状态、充电桩状态
- 数据模型采用 `字典类型表 + 字典项表`
- 页面暂不支持新增字典类型，但数据库结构允许后续扩展
- 系统管理员可维护这 3 类字典项
- 业务页面后续可复用这些字典项作为选项来源
