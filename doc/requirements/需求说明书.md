# 充电站管理系统需求文档

## 1. 文档目的

本文档用于明确充电站管理系统第一期的业务目标、页面结构、角色权限、核心数据模型、用户操作旅程与技术方案，作为后续产品设计、详细任务拆解与开发实施的基线。

## 2. 项目目标

建设一个面向内部管理人员使用的充电站管理系统，部署在公网环境，支持 PC 浏览器使用，同时支持手机端自适应访问，并满足以下核心目标：

- 统一维护充电站基础信息。
- 管理充电桩信息，并预留后续扩展到单枪管理的能力。
- 管理股东主档及其与充电站之间的持股关系。
- 支持系统管理员与业务管理员两类角色的权限分工。
- 支持对关键业务变更、状态变更、股权调整、平台维护与账号管理进行操作审计。
- 提供站点页、股东页、日志页可视化的历史变化时间线。

## 3. 第一期开 scope

### 3.1 包含范围

- 登录与密码管理
- 用户角色管理
- 平台字典管理
- 充电站管理
- 充电桩管理
- 股东主档管理
- 股东持股关系管理
- 股权调整独立页面
- 操作日志与时间线展示
- 首页数据概览与快捷入口
- PC + 手机自适应后台

### 3.2 第一阶段不包含

- 用户自助注册
- 短信验证码登录
- 微信扫码登录
- 外部平台真实接口对接
- 平台接口参数保存
- 单枪级管理页面
- 版本快照式历史还原
- 多端分离的独立手机管理端

## 4. 角色与权限

系统包含两类角色：系统管理员、业务管理员。

### 4.1 系统管理员

- 默认账号：`admin`
- 初始化密码：本地开发默认回退为 `123456`，也可通过环境变量 `CSZD_DEFAULT_ADMIN_PASSWORD` 覆盖；生产环境必须通过部署配置覆盖默认值
- 允许登录系统
- 可修改自己的密码
- 可创建业务管理员账号
- 可重置业务管理员密码
- 可维护平台字典
- 可查看全局操作日志
- 可下载股东导入模板、股东关系导入模板
- 可导入股东主档（仅批量新增，不允许修改或删除已有股东）
- 可导入充电站与股东关系（仅批量新增，不允许修改或删除已有关系）
- 不允许直接新增、修改充电站、充电桩、股东及持股关系业务数据（Excel 批量导入为唯一例外，仅新增）

### 4.2 业务管理员

- 使用手机号作为登录账号
- 由系统管理员手工创建
- 首次登录不强制修改初始密码
- 可修改自己的密码
- 可新增、修改充电站
- 可新增、修改充电桩
- 可新增、修改股东主档
- 可维护充电站与股东的持股关系
- 可进行股权调整
- 可查看全局操作日志
- 可下载股东导入模板、股东关系导入模板
- 不可使用股东导入功能（批量新增仅系统管理员可用）
- 不可使用股东关系导入功能（批量新增仅系统管理员可用）

### 4.3 数据权限

- 业务管理员为全站可管模式。
- 所有业务管理员均可看到并维护所有充电站、充电桩、股东及持股关系数据。

## 5. 技术方案基线

### 5.1 总体方案

- 前端：`Vue 3 + Element Plus`
- 后端：`Java` 技术栈
- 数据库：`MySQL`
- 部署方式：公网部署
- 登录方式：账号密码登录
- 访问方式：同一套 Web 后台自适应支持 PC 与手机

### 5.2 方案原则

- 采用标准后台型方案，优先保证结构清晰、维护稳定与后续扩展能力。
- 审计展示采用时间线事件流，不做重型版本管理系统。
- 股权调整作为独立业务页面处理，避免复杂关系编辑挤压在详情页中。
- 平台先做字典管理，数据模型为未来平台对接预留扩展空间。

## 6. 信息架构与页面结构

## 6.1 顶层菜单

建议第一期左侧菜单结构如下：

- 首页
- 充电站管理
- 股东管理
- 平台管理
- 操作日志
- 用户管理
- 我的账号

### 6.2 首页

首页采用数据概览页形式，重点展示业务概览与快捷入口。

#### 展示内容

- 充电站总数
- 充电站按状态统计
- 充电桩总数
- 充电桩按状态统计
- 股东总数
- 最近操作记录

#### 快捷入口

- 新增充电站
- 进入股东管理
- 查看操作日志
- 平台管理

### 6.3 充电站管理

#### 页面模式

- 使用 `列表 + 详情页` 结构。
- 列表页负责查询、筛选、分页与进入详情。
- 详情页采用 `单页分区模式`，不采用标签页。

#### 列表页核心能力

- 按充电站名称搜索
- 按平台筛选
- 按状态筛选
- 查看站点基础信息摘要
- 进入站点详情
- 新增充电站
- 下载股东关系导入模板（Excel，系统管理员与业务管理员均可见）
- 导入股东关系（批量新增，仅系统管理员可见）

#### 股东关系导入

- 提供 Excel 模板下载，模板第一列预填全部充电站名称，用户只需填写股东名称与股份占比。
- 导入只允许新增持股关系，以（充电站名称，股东名称）为联合业务主键去重，不允许修改或删除已有关系。
- 导入需做数据验证，任一数据非法则整体不落库并返回逐行错误，防止批量破坏系统数据。
- 导入的每条关系进入对应充电站的操作日志 / 时间线。

#### 详情页分区

- 基础信息
- 充电桩管理
- 股东信息
- 历史变化 / 时间线

### 6.4 股东管理

股东是独立实体，需要有独立的股东管理菜单。

#### 列表页核心能力

- 查看股东主档列表
- 按名称搜索
- 按状态筛选
- 新增股东
- 下载股东导入模板（Excel，系统管理员与业务管理员均可见）
- 导入股东（批量新增，仅系统管理员可见）
- 进入股东详情

#### 股东导入

- 提供 Excel 模板下载，模板为三列：股东名称（必填）、联系人（选填）、联系电话（选填）。
- 导入只允许新增股东，以股东名称为业务主键去重与存在性校验，不允许修改或删除已有股东。
- 导入需做数据验证，任一数据非法则整体不落库并返回逐行错误，防止批量破坏系统数据。

#### 详情页核心能力

- 展示股东基础信息
- 展示该股东关联的充电站
- 展示历史变化时间线
- 默认展示该股东在所有充电站的相关事件
- 支持按充电站筛选时间线

### 6.5 平台管理

平台管理第一期为独立字典管理页面，仅系统管理员可维护。

#### 第一阶段范围

- 平台名称
- 平台编码或简称
- 平台状态

#### 第一阶段不包含

- API 地址
- AppId
- AppSecret / 密钥
- 实时对接配置

### 6.6 用户管理

仅系统管理员可见。

#### 核心能力

- 新增业务管理员
- 查看业务管理员列表
- 启用 / 停用业务管理员账号
- 重置业务管理员密码

### 6.7 我的账号

系统管理员、业务管理员均可见，用于：

- 查看本人账号信息
- 修改本人密码

### 6.8 操作日志

提供独立的全局日志中心页面。

#### 可见角色

- 系统管理员
- 业务管理员

#### 日志页查询能力

- 按时间范围筛选
- 按操作人筛选
- 按对象类型筛选
- 按充电站筛选
- 查看事件详情

#### 对象类型示例

- 充电站新增 / 修改 / 状态变更
- 充电桩新增 / 修改 / 状态变更
- 股东主档新增 / 修改 / 状态变更
- 持股关系新增 / 退出 / 占比调整
- 平台字典新增 / 修改 / 状态变更
- 业务管理员新增 / 重置密码 / 状态变更

## 7. 核心数据模型

### 7.1 平台

平台为独立字典实体，供充电站选择。

建议字段：

- 平台ID
- 平台名称
- 平台编码 / 简称
- 状态
- 创建时间
- 更新时间

### 7.2 充电站

#### 基础属性

- 名称
- 系统ID
- 平台ID
- 所在平台
- 地址
- 联系人
- 生命周期状态

#### 规则

- `系统ID` 由系统自动生成，且全局唯一
- `平台ID` 由人工维护，可为空
- `平台ID` 在同一平台内唯一
- `所在平台` 必须从平台字典中选择

#### 生命周期状态

- 签合同
- 建设中
- 运营中
- 运营异常
- 停用

#### 状态规则

- 状态为单一状态
- 允许任意切换
- 状态变更时备注为可选
- 新增充电站默认状态为 `签合同`

### 7.3 充电桩

充电桩归属于某一充电站。

#### 属性

- 桩编号
- 所属充电站
- 充电类型：快充 / 慢充
- 充电枪数量
- 生命周期状态

#### 规则

- 当前管理粒度为“桩级”
- 第一阶段不单独管理每把枪
- 技术上需预留未来扩展到枪级管理的能力
- 桩编号由系统自动生成
- 桩编号为全局唯一编号

#### 生命周期状态

- 运营中
- 运营异常
- 停用

#### 状态规则

- 状态为单一状态
- 允许任意切换
- 状态变更时备注为可选
- 新增充电桩默认状态为 `运营中`

### 7.4 股东主档

股东是全局独立实体，可被多个充电站引用。

#### 基础属性

- 股东名称
- 联系人
- 联系电话
- 状态

#### 规则

- 同一股东在不同充电站之间共用一份主档信息
- 修改股东主档信息后，所有关联站点同步使用最新主档信息

#### 股东主档状态

- 启用
- 停用

#### 说明

- `退股` 不属于股东主档状态
- 退股发生在“股东与充电站的持股关系”层面

### 7.5 持股关系

持股关系是“股东 - 充电站”之间的独立业务关系。

#### 属性

- 所属充电站
- 关联股东
- 股份占比
- 关系状态
- 生效时间
- 创建时间
- 更新时间

#### 关系状态

- 持股中
- 已退出

#### 规则

- 一个股东可以关联多个充电站
- 一个充电站可以有多个股东
- 同一充电站下所有 `持股中` 的股东股份占比总和必须等于 `100%`
- 退股时必须在同一次操作中同步调整其他股东占比，保证总和仍为 `100%`
- 股份调整为立即生效，不单独指定未来生效时间

## 8. 关键业务规则

### 8.1 充电站新增流程

新增站点采用“两段式”：

1. 先创建充电站基础信息
2. 保存成功后进入详情页
3. 在详情页继续新增充电桩
4. 在详情页继续新增股东关系

不采用一次性整站整资料录入，也不采用多步向导。

### 8.2 充电桩管理规则

- 每个充电站下可新增多个充电桩
- 每个桩记录快充 / 慢充标识
- 每个桩记录充电枪数量
- 充电桩不执行物理删除
- 如不再使用，通过状态切换到 `停用`

### 8.3 股东管理规则

- 股东先作为独立主档创建
- 在充电站详情页中选择已有股东建立持股关系
- 同一股东可复用于多个充电站
- 股东主档停用后，原则上不允许继续建立新的持股关系

### 8.4 股权调整规则

股权调整属于相对专业的操作，需要独立页面处理。

#### 交互方式

- 在充电站详情页的股东分区中点击“股权调整”
- 进入独立页面
- 页面展示该充电站全部股东及当前持股情况
- 支持一次性调整多个股东占比
- 保存前校验当前 `持股中` 股东占比总和为 `100%`

#### 典型场景

- 某股东退股，同时重分配其他股东占比
- 新增股东并同步调整其他股东占比
- 多个股东同时变更持股比例

#### 结果要求

- 形成一条清晰的“股权调整事件”
- 事件进入充电站时间线
- 事件进入相关股东时间线
- 事件进入全局日志中心

### 8.5 删除策略

第一期不采用业务对象删除机制。

- 充电站不删除，通过状态切换管理
- 充电桩不删除，通过状态切换管理
- 股东主档不删除，通过状态切换管理
- 持股关系通过 `已退出` 表示退出，不物理删除历史

## 9. 历史变化与操作审计

### 9.1 展示方式

历史变化采用 `时间线事件流` 作为统一展示方式。

#### 特征

- 按时间倒序展示
- 每条事件显示事件摘要
- 支持查看事件详情
- 不做默认字段级 Diff 主视图
- 不做版本快照视图

### 9.2 时间线分布位置

- 充电站详情页展示该站全部相关事件
- 股东详情页展示该股东全部相关事件，并可按充电站筛选
- 全局操作日志页展示系统范围内全部日志事件

### 9.3 审计覆盖范围

#### 业务管理员操作

- 新增充电站
- 修改充电站
- 充电站状态变更
- 新增充电桩
- 修改充电桩
- 充电桩状态变更
- 新增股东主档
- 修改股东主档
- 股东主档状态变更
- 建立持股关系
- 持股关系退出
- 股权调整

#### 系统管理员操作

- 新增业务管理员
- 重置业务管理员密码
- 业务管理员状态变更
- 新增平台
- 修改平台
- 平台状态变更

### 9.4 日志记录内容

每条日志建议记录：

- 操作时间
- 操作账号
- 操作角色
- 操作对象类型
- 操作对象标识
- 操作类型
- 修改前内容
- 修改后内容
- 备注信息

## 10. 用户操作旅程

### 10.1 业务管理员新增充电站

1. 登录系统
2. 进入首页查看概览
3. 点击“新增充电站”
4. 填写站点基础信息并保存
5. 系统自动生成站点系统ID
6. 保存成功后进入充电站详情页
7. 在详情页中新增充电桩
8. 在详情页中选择或新增股东，并建立持股关系
9. 进入股权调整页面完成占比校验与分配
10. 返回详情页查看时间线记录

### 10.2 业务管理员维护充电桩

1. 进入充电站列表
2. 打开某充电站详情
3. 在充电桩分区新增或修改桩信息
4. 系统自动生成桩编号
5. 如设备停用或异常，直接修改状态
6. 变更记录进入时间线和日志页

### 10.3 业务管理员进行股权调整

1. 进入某充电站详情
2. 打开股东分区
3. 点击“股权调整”
4. 进入独立股权调整页
5. 一次性修改多个股东占比
6. 系统提示：若合计不等于 `100%`，弹窗提示「充电站持股数合计不等于100%，是否确认。」，用户确认后继续保存
7. 保存成功后写入股权调整事件
8. 在站点详情、股东详情、日志中心可查看事件

### 10.4 系统管理员创建业务管理员

1. 使用 `admin` 账号登录
2. 进入用户管理
3. 新增业务管理员
4. 使用手机号作为登录账号
5. 设置初始密码
6. 保存后业务管理员可直接登录
7. 后续如忘记密码，系统管理员可进行重置

### 10.5 系统管理员维护平台字典

1. 登录系统
2. 进入平台管理
3. 新增或修改平台基础信息
4. 保存后平台立即可在充电站表单中选择
5. 平台操作同时进入日志中心

## 11. 移动端适配原则

第一期采用同一套后台系统自适应支持手机访问，不单独开发独立手机端。

### 适配原则

- 列表页在手机端需转为更紧凑布局
- 详情页的单页分区结构需适配手机纵向滚动
- 表单控件需保证手机可点击、可输入
- 独立页面型操作，如股权调整页，在手机端优先采用纵向表格或卡片式编辑
- 弹窗类复杂交互尽量减少，避免在手机端造成操作拥挤

## 12. 非功能要求

### 12.1 安全

- 公网部署必须进行账号密码鉴权
- 密码不得明文存储
- 重置密码操作需记录日志
- 关键管理操作需进行权限校验

### 12.2 可维护性

- 数据模型需为后续外部平台对接预留空间
- 充电设备模型需预留从“桩级”扩展到“枪级”的能力
- 日志模型需兼容系统管理员与业务管理员两类事件

### 12.3 可读性与易用性

- PC 端优先保证后台表格、表单与详情页结构清晰
- 手机端优先保证核心维护动作可完成，不追求独立移动端视觉形态
- 时间线内容需让业务人员直接看懂发生了什么变更

## 13. 推荐实施方向

本项目第一期建议采用：

- 标准后台型信息架构
- 首页概览 + 快捷入口
- 充电站 `列表 + 详情`
- 详情页采用单页分区
- 股东独立主档管理
- 股权调整独立页面
- 时间线事件流审计展示
- 平台字典先管理、后对接

该方案在开发复杂度、后续扩展能力、PC 与手机兼容性之间较平衡，适合作为第一期上线基线。

## 14. 当前已确认结论摘要

- 使用端：PC 后台 + 手机自适应
- 手机端能力：完整可操作
- 部署：公网部署
- 业务管理员权限：全站可管
- 充电设备粒度：先按桩管理，预留枪扩展
- 站点页面：列表 + 详情页
- 详情布局：单页分区
- 新增站点方式：先建站，再补充桩和股东
- 日志：记录增改状态变更及关键管理操作，页面可视
- 删除策略：不用删除，改用状态管理
- 登录：账号密码登录
- 平台：独立字典管理，第一期不做接口参数
- 前端：Vue 3 + Element Plus
- 后端：Java
- 数据库：MySQL
- 股东：独立实体，可关联多个站点
- 股东主档状态：启用 / 停用
- 持股关系状态：持股中 / 已退出
- 股份调整：必须同时调整其他股东占比，合计等于 100%
- 状态切换：允许任意切换
- 系统管理员：不操作业务数据，只管账号与平台
- 首页：数据概览 + 快捷入口
- 适配方式：同一套自适应后台
