# 操作日志功能启动问题修复报告

## 问题描述

后台启动时报错:
```
org.springframework.beans.factory.UnsatisfiedDependencyException: Error creating bean with name 'operationLogRepository'
Caused by: org.hibernate.query.sqm.UnknownPathException: Could not resolve attribute 'shareholder' of 'com.changsha.zhongdian.shareholding.entity.Shareholding'
```

## 问题根因

在 `OperationLogRepository` 的JPQL查询中,错误地使用了实体关联路径(`sh.shareholder.id`, `sh.station.id`),但 `Shareholding` 实体采用了**解耦设计**,只存储主键ID字段,没有实体关联:

```java
// Shareholding实体的实际设计
@Entity
public class Shareholding {
    private Long shareholderId;  // 只存主键ID
    private Long stationId;      // 只存主键ID
    // 没有 @ManyToOne 关联
}
```

## 修复方案

### 修改前
```java
@Query("SELECT l FROM OperationLog l WHERE " +
       "(l.targetType = 'SHAREHOLDER' AND l.targetId = :shareholderId) OR " +
       "(l.targetType = 'SHAREHOLDING' AND l.targetId IN " +
       "(SELECT CAST(sh.id AS string) FROM Shareholding sh WHERE sh.shareholder.id = :shareholderId)) " +
       "ORDER BY l.createdAt DESC")
```

### 修改后
```java
@Query("SELECT l FROM OperationLog l WHERE " +
       "(l.targetType = com.changsha.zhongdian.operationlog.entity.OperationTargetType.SHAREHOLDER AND CAST(l.targetId AS long) = :shareholderId) OR " +
       "(l.targetType = com.changsha.zhongdian.operationlog.entity.OperationTargetType.SHAREHOLDING AND CAST(l.targetId AS long) IN " +
       "(SELECT sh.id FROM Shareholding sh WHERE sh.shareholderId = :shareholderId)) " +
       "ORDER BY l.createdAt DESC")
```

### 主要修改点

1. **修正字段名**: `sh.shareholder.id` → `sh.shareholderId`, `sh.station.id` → `sh.stationId`
2. **修正枚举比较**: 字符串字面量 `'SHAREHOLDER'` → 完整枚举类型 `OperationTargetType.SHAREHOLDER`
3. **修正类型转换**: `CAST(sh.id AS string)` → 直接使用 `sh.id` (Long类型), `CAST(l.targetId AS long)` 转换字符串ID为数字

## 经验总结

### JPQL查询注意事项

1. **了解实体设计**: 在编写JPQL前,必须先查看实体类的实际字段定义
2. **解耦设计识别**: 注意识别"只存ID不做关联"的解耦设计模式
3. **枚举类型比较**: JPQL中比较枚举时使用完整类路径,不用字符串字面量
4. **类型转换**: 注意字段的实际类型,合理使用CAST
5. **启动时验证**: Spring Data JPA在启动时会验证所有@Query,确保查询语法正确

### 测试策略

1. **Repository层测试**: 使用`@DataJpaTest`和`TestEntityManager`验证JPQL查询
2. **Service层测试**: 使用Mockito验证业务逻辑
3. **启动验证**: 确保应用能正常启动,Repository查询能通过Spring验证
