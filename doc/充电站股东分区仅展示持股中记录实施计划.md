# 充电站股东分区仅展示持股中记录实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让充电站详情页股东信息区域只展示持股中（`ACTIVE`）股东，已退出股东不展示；通过接口参数化实现，为时间线预留查询能力。

**Architecture:** 后端 `ShareholdingQueryService.getStationShareholdings` 增加可选 `holdingStatus` 参数，`ShareholdingController` 接收并透传；前端 `StationShareholderSection` 调用时固定传 `ACTIVE`；历史记录仍保留在 `biz_shareholding` 表中，展示口径收紧但不物理删除。

**Tech Stack:** Spring Boot 3.3.2 / Java 17 / JUnit 5 / Mockito；Vue 3 / TypeScript / Element Plus / Vitest；Gradle；MySQL。

```java
// 站点详情股东分区列表：站点是路径资源，站点不存在时与站点详情接口同口径返回 404
public List<StationShareholdingListItemResponse> getStationShareholdings(Long stationId) {
    return getStationShareholdings(stationId, null);
}

public List<StationShareholdingListItemResponse> getStationShareholdings(Long stationId, HoldingStatus holdingStatus) {
    if (stationId == null || stationId <= 0L) {
        throw new BusinessException("VALIDATION_ERROR", "充电站不存在", HttpStatus.BAD_REQUEST);
    }
    if (!stationRepository.existsById(stationId)) {
        throw new BusinessException("STATION_NOT_FOUND", "充电站不存在", HttpStatus.NOT_FOUND);
    }
    // 充电站详情股东分区默认只展示持股中记录；传 null 时返回全部，供后续时间线复用
    List<StationShareholdingListItemProjection> projections = holdingStatus == null
            ? shareholdingRepository.findStationShareholderListItems(stationId)
            : shareholdingRepository.findByStationIdAndHoldingStatus(stationId, holdingStatus.name());
    return projections.stream()
            .map(item -> new StationShareholdingListItemResponse(...))
            .toList();
}
```

```java
@GetMapping("/stations/{stationId}/shareholdings")
public ApiResponse<List<StationShareholdingListItemResponse>> getStationShareholdings(
        @PathVariable Long stationId,
        @RequestParam(required = false) String holdingStatus
) {
    HoldingStatus status = resolveHoldingStatus(holdingStatus);
    return ApiResponse.success(
            shareholdingQueryService.getStationShareholdings(stationId, status)
    );
}

private HoldingStatus resolveHoldingStatus(String holdingStatus) {
    if (holdingStatus == null || holdingStatus.isBlank()) {
        return null;
    }
    try {
        return HoldingStatus.valueOf(holdingStatus);
    } catch (IllegalArgumentException exception) {
        throw new BusinessException(
                "VALIDATION_ERROR",
                "持股状态参数非法，仅支持 ACTIVE / EXITED",
                HttpStatus.BAD_REQUEST
        );
    }
}
```
