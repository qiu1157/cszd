# 充电站管理系统验收清单

## 1. 使用说明

本清单用于开发完成后的功能验收、联调验收与上线前检查。

验收原则：

- 先验主流程，再验边界条件。
- 先验权限隔离，再验功能完整性。
- 先验数据正确性，再验页面表现。

## 2. 登录与权限

- [ ] 默认系统管理员 `admin` 可在数据库初始化完成后使用初始化密码正常登录。
- [ ] 默认系统管理员登录成功后会更新最后登录时间。
- [ ] 系统管理员登录成功后默认进入首页概览页。
- [ ] 系统管理员可修改本人密码。
- [ ] 业务管理员可使用手机号 + 密码登录。
- [ ] 业务管理员登录成功后会更新最后登录时间。
- [ ] 业务管理员可修改本人密码。
- [ ] 业务管理员首次登录不强制改密。
- [ ] 所有登录均基于数据库用户表认证，不允许回退到内存账号。
- [ ] 未登录访问受保护页面时会被拦截到登录页。
- [ ] 系统管理员可见 `用户管理`、`系统字典`、`操作日志` 等应有菜单。
- [ ] 业务管理员不可见 `用户管理`。
- [ ] 业务管理员不可维护系统字典。
- [ ] 系统管理员不可直接维护充电站、充电桩、股东、持股关系业务数据。

## 3. 用户管理

- [ ] 系统管理员可新增业务管理员。
- [ ] 新增业务管理员时手机号作为登录账号。
- [ ] 手机号格式校验正确。
- [ ] 系统可避免重复手机号账号。
- [ ] 系统管理员可重置业务管理员密码。
- [ ] 重置密码时需手动输入 `6-20` 位且同时包含字母和数字的新密码。
- [ ] 系统管理员可启用业务管理员。
- [ ] 系统管理员可停用业务管理员。
- [ ] 停用后的业务管理员无法继续登录。
- [ ] 业务管理员列表可展示最后登录时间。
- [ ] 用户管理相关操作被记录到日志中心。

## 4. 系统字典

- [ ] 系统管理员可进入系统字典页面。
- [ ] 访问旧路由 `/platforms` 时会自动跳转到 `/system-dictionaries`。
- [ ] 系统字典第一阶段至少包含：平台、充电站状态、充电桩状态。
- [ ] 系统管理员可新增平台字典项。
- [ ] 系统管理员可修改平台字典项。
- [ ] 系统管理员可启用 / 停用平台字典项。
- [ ] 系统管理员可新增充电站状态字典项。
- [ ] 系统管理员可新增充电桩状态字典项。
- [ ] 系统字典列表可正常展示名称、编码、状态、排序。
- [ ] 第一阶段系统字典页面不出现 API 地址、AppId、密钥等字段。
- [ ] 系统字典维护操作被记录到日志中心。

## 5. 首页概览

- [ ] 首页展示充电站总数。
- [ ] 首页展示充电站状态统计。
- [ ] 首页展示充电桩总数。
- [ ] 首页展示充电桩状态统计。
- [ ] 首页展示股东总数。
- [ ] 首页展示最近操作记录。
- [ ] 首页存在快捷入口：新增充电站、股东管理、操作日志、系统字典。

## 6. 充电站管理

- [x] 可新增充电站。
- [x] 新增充电站时系统自动生成全局唯一充电站编号。
- [x] 新增充电站默认状态为 `签合同`。
- [x] 新增 / 编辑充电站表单中的“所在平台”选项来自系统字典中的平台类型。
- [x] 充电站详情页交付前，新增成功后先返回列表页，并能看到新建记录。
- [x] 可编辑充电站名称、平台、地址、联系人等信息。
- [x] 列表页支持按名称搜索。
- [x] 列表页支持按平台筛选。
- [x] 列表页支持按状态筛选。
- [x] 列表页支持分页浏览。
- [x] 点击记录可进入充电站详情页。
- [x] 详情页采用单页分区，不是标签页结构。
- [x] 详情页包含基础信息、充电桩管理、股东信息、历史变化时间线。
- [x] 充电站状态可在 `签合同 / 建设中 / 运营中 / 运营异常 / 停用` 之间切换。
- [x] 状态切换允许任意切换。
- [x] 状态变更原因备注为可选。
- [x] 充电站不提供物理删除能力。

## 7. 充电桩管理

- [x] 可在充电站详情页新增充电桩。
- [x] 新增充电桩时系统自动生成全局唯一桩编号。
- [x] 充电桩可录入快充 / 慢充类型。
- [x] 充电桩可录入充电枪数量。
- [x] 新增充电桩默认状态为 `运营中`。
- [x] 可编辑充电桩信息。
- [x] 充电桩状态可在 `运营中 / 运营异常 / 停用` 之间切换。
- [x] 状态切换允许任意切换。
- [x] 状态变更原因备注为可选。
- [x] 充电桩不提供物理删除能力。

## 8. 股东主档管理

- [x] 存在独立的股东管理菜单。
- [x] 可新增股东主档。
- [x] 可编辑股东主档名称、联系人、联系电话。
- [x] 股东主档状态只有 `启用 / 停用`。
- [ ] 股东主档不存在“退股”状态。
- [ ] 同一股东主档可被多个充电站复用。
- [ ] 修改股东主档信息后，关联站点展示同步更新。
- [ ] 停用股东后不能继续新增新的持股关系。

### 8.1 股东 Excel 批量导入

- [ ] 股东名称为业务主键：`shareholder_name` 存在唯一索引，手工新增重名股东被拦截。
- [ ] 股东列表页提供「下载模板」按钮，系统管理员与业务管理员均可见。
- [ ] 股东列表页提供「导入股东」按钮，仅系统管理员可见（业务管理员不可见，且后端返回 `403`）。
- [ ] 下载的模板为 Excel（`.xlsx`），含「股东名称 / 联系人 / 联系电话」三列表头。
- [ ] 导入只允许新增：文件内股东名称不重复，库内已存在的名称被拒绝（不修改）。
- [ ] 导入数据校验：股东名称必填且 ≤128 字符，联系人 ≤64，联系电话 ≤20。
- [ ] 任一数据非法时整体不导入，并返回逐行错误（行号 + 原因）。
- [ ] 导入成功后仅落库新增记录，并写入一条导入操作日志。

## 9. 持股关系与股权调整

- [ ] 可在充电站详情页为站点关联已有股东。
- [ ] 可创建该站点与股东的持股关系。
- [ ] 持股关系状态为 `持股中 / 已退出`。
- [ ] 退股发生在持股关系层，不影响股东主档状态。
- [ ] 持股中占比合计不等于 `100%` 时，保存前弹窗确认，确认后可保存；站点无持股中股东时不提示。
- [ ] 当某股东退股时，系统要求同步调整其他股东占比。
- [ ] 站点详情页存在“股权调整”入口。
- [ ] 点击后进入独立的股权调整页面。
- [ ] 独立页面可一次性调整多个股东占比。
- [ ] 保存前系统提示占比合计不等于 `100%`，用户确认后完成保存。
- [ ] 股权调整默认立即生效。
- [ ] 股权调整成功后生成一条股权调整事件。
- [x] 站点详情股东信息区域仅展示持股中股东。
- [x] 已退出股东不在充电站详情股东信息区域出现。
- [x] 退股后站点详情股东分区立即刷新，已退出股东从该区域消失。

### 9.1 股东关系 Excel 批量导入

- [ ] 充电站名称为业务主键：`station_name` 存在唯一索引，手工新增重名充电站被拦截。
- [ ] 充电站列表页提供「下载模板」按钮，系统管理员与业务管理员均可见。
- [ ] 充电站列表页提供「导入关系」按钮，仅系统管理员可见（业务管理员不可见，且后端返回 `403`）。
- [ ] 下载的模板为 Excel（`.xlsx`），第一列预填全部充电站名称，含「充电站名称 / 股东名称 / 股份占比」三列表头。
- [ ] 导入只允许新增：文件内（充电站名称，股东名称）组合不重复，库内已持股中的组合被拒绝（不修改）。
- [ ] 导入数据校验：充电站名称存在、股东名称存在且启用、股份占比为 `0~100` 且最多 2 位小数。
- [ ] 任一数据非法时整体不导入，并返回逐行错误（行号 + 原因）。
- [ ] 导入成功后仅落库新增持股关系，每条关系进入对应充电站操作日志 / 时间线（`关联股东`）。

## 12. 操作日志实现质量检查

### 12.1 后端代码检查

- [ ] 所有 CommandService 写操作方法返回实体对象（不返回 Long ID）。
- [ ] 所有 CommandService 写操作方法已添加 `@LogOperation` 注解。
- [ ] 注解的 `targetType` 配置正确（STATION/PILE/SHAREHOLDER/SHAREHOLDING）。
- [ ] 注解的 `operationType` 配置正确（CREATE/UPDATE/DELETE/EXIT）。
