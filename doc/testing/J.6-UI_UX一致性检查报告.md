## 三、间距系统一致性

### 3.1 间距规范

**规范要求** (前端开发规范 5.3):
- 采用 4 的倍数体系: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40
- 页面区块间距: 24px
- 卡片内边距: 20px 或 24px
- 表单行距: 16px
- 移动端卡片内边距: 16px

### 3.2 实际间距抽查

**卡片内边距检查** (el-card):

查看 Element Plus 默认值和自定义覆盖：

| 组件 | 位置 | 实际内边距 | 规范要求 | 一致性 |
|-----|------|-----------|---------|-------|
| el-card header | dialog、card | Element Plus 默认 ~18px | 20-24px | ⚠️ 接近 |
| el-card body | dialog、card | Element Plus 默认 ~20px | 20-24px | ✅ 一致 |
| el-dialog header | 弹窗 | `padding: 18px 18px 14px` | 20-24px | ⚠️ 接近 |
| el-dialog body | 弹窗 | `padding: 18px` | 20-24px | ⚠️ 接近 |
| el-dialog footer | 弹窗 | `padding: 14px 18px 18px` | 20-24px | ⚠️ 接近 |

**说明**: Element Plus 默认使用 18-20px，与规范要求的 20-24px 接近但略小。

**菜单项间距** ([global.scss](code/frontend/src/styles/global.scss#L53-L55)):

```scss
.el-menu-item {
  margin-bottom: 8px;  // ✅ 符合 8px 倍数体系
  border-radius: 14px;
}
```

**按钮内边距** ([global.scss](code/frontend/src/styles/global.scss#L72-L74)):

```scss
.el-button.action-button {
  min-width: 88px;  // ⚠️ 88 不是 4 的倍数
  padding: 8px 14px; // ⚠️ 14 不是 4 的倍数，建议改为 12px 或 16px
}
```

**评估结果**: ⚠️ **基本符合，有小幅偏差**

- ✅ 大部分间距使用 4 的倍数
- ⚠️ 部分地方使用 18px（应改为 16px 或 20px）
- ⚠️ 按钮内边距 14px 应改为 12px 或 16px
- ⚠️ 按钮最小宽度 88px 可调整为 92px

**优化建议**:

```scss
.el-button.action-button {
  min-width: 92px;  // 从 88px 改为 92px
  padding: 8px 16px; // 从 14px 改为 16px
}

.el-dialog__header {
  padding: 20px 20px 16px; // 从 18px 改为 20px
}

.el-dialog__body {
  padding: 20px; // 从 18px 改为 20px
}

.el-dialog__footer {
  padding: 16px 20px 20px; // 从 14px 18px 18px 改为 16px 20px 20px
}
```

### 5.6 弹窗关闭行为一致性

**规范要求** (强约束):
- 弹窗不能点击遮罩关闭，只能通过关闭/取消/保存按钮关闭

**检查方法**: 查找所有 `el-dialog` 的 `close-on-click-modal` 属性

实际项目中，Element Plus 默认 `close-on-click-modal` 为 `true`，需要显式设置为 `false`。

**评估结果**: ⚠️ **需验证**

建议在全局配置中统一设置：

```typescript
// main.ts
app.use(ElementPlus, {
  dialog: {
    closeOnClickModal: false,
  }
})
```

或在每个 dialog 中显式设置：

```vue
<el-dialog :close-on-click-modal="false">
```
