# 部署与运维指南

本文档汇总充电站管理系统第一期的构建、部署与运维步骤。数据库脚本细节见 `code/db/README.md` 与 `code/db/schema.sql`。

## 1. 环境要求

| 组件 | 要求 |
|------|------|
| 后端 JDK | 17+（Spring Boot 3.3） |
| 前端 Node | 建议 18+（Vite 8 / Vue 3.5） |
| 数据库 | MySQL 8.x，字符集 `utf8mb4`，排序规则 `utf8mb4_0900_ai_ci` |

## 2. 配置注入

连接信息与密钥一律通过**环境变量**注入，禁止把真实值写入仓库。可用变量（参见根目录 `.env.example`）：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `CSZD_DB_HOST` | `localhost` | 数据库主机 |
| `CSZD_DB_PORT` | `3306` | 数据库端口 |
| `CSZD_DB_NAME` | `cszd_db` | 数据库名（标准口径） |
| `CSZD_DB_USER` | `cszd` | 数据库账号 |
| `CSZD_DB_PASSWORD` | 空 | 数据库密码（必须注入） |
| `CSZD_DEFAULT_ADMIN_PASSWORD` | `123456` | 默认管理员 `admin` 初始密码；**生产必须覆盖** |
| `CSZD_DEV_BIZ_ACCOUNT` | 空 | 开发期业务管理员账号（本地覆盖） |
| `CSZD_DEV_BIZ_PASSWORD` | 空 | 开发期业务管理员密码（本地覆盖） |

> 注意：数据库名在仓库中统一为 `cszd_db`；历史文档曾混用 `cszd_dev_db` / `charging_station_system`，均已按 `cszd_db` 收敛，旧命名仅为开发期痕迹，不代表当前口径。

## 3. 数据库初始化

1. 创建数据库并执行 `code/db/schema.sql`（含全部 `sys_*` / `biz_*` 表结构与默认字典初始化依据）。
2. 建表历史增量脚本位于 `code/db/migrations/`，按时间顺序执行；从零初始化时以 `schema.sql` 为准。
3. 授权示例（按安全策略收紧来源 IP）：

```sql
CREATE USER IF NOT EXISTS 'cszd'@'%' IDENTIFIED BY '<你的密码>';
GRANT ALL PRIVILEGES ON cszd_db.* TO 'cszd'@'%';
FLUSH PRIVILEGES;
```

## 4. 后端启动

```bash
cd code/backend
./gradlew bootRun          # Linux / macOS
# Windows PowerShell:
#   $env:CSZD_DB_PASSWORD="<密码>"; .\gradlew.bat bootRun
```

- 默认端口 `8080`。
- 健康检查：`GET http://localhost:8080/api/health`。
- 若本机无 `javac`，`gradlew.bat` 会自动下载 Temurin JDK 17 到 `code/backend/.gradle/jdks/`（需联网）。
- 默认系统管理员 `admin` 由后端启动时按 `CSZD_DEFAULT_ADMIN_PASSWORD` 自动初始化（未设置时回退 `123456`，生产必须覆盖）。

## 5. 前端启动

```bash
cd code/frontend
npm install
npm run dev                # 开发模式
npm run build              # 生产构建（tsc + vite build）
npm run lint               # ESLint 检查
npm run format             # Prettier 格式化
npm run test               # 单元测试（vitest）
```

## 6. 生产部署注意事项

- **密码策略**：默认管理员密码必须通过环境变量覆盖，密码采用 PBKDF2 哈希存储，不落明文。
- **鉴权**：所有受保护接口由 `AuthInterceptor` 校验 Bearer Token，菜单与接口均执行角色鉴权。
- **跨域**：生产 CORS 白名单通过配置维护，避免在源码中固化内网/公网地址。
- **密钥与连接串**：真实数据库密码、公网地址、Token 密钥一律经环境变量或私有配置注入，不入库。
- **日志审计**：关键写操作由 `@LogOperation` 统一记录到 `biz_operation_log`，日志写入使用 `REQUIRES_NEW` 独立事务，避免与主业务事务耦合。

## 7. 常见问题

- **`Access denied for user 'cszd'@'...'`**：数据库未授权该来源主机，参考第 3 节授权。
- **启动连接超时**：后端已配置 HikariCP 短超时（5s）与连接保活（30s），确认网络与账号授权。
- **中文路径构建异常**：若在含中文路径的 Windows 目录构建后端测试报 `ClassNotFoundException`，可用纯 ASCII 目录联接规避（详见 `doc/development/开发流程与规范.md`）。
