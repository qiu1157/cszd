# 充电站管理系统验收清单

## 1. 使用说明

本清单用于开发完成后的功能验收、联调验收与上线前检查。

验收原则：

- 先验主流程，再验边界条件。
- 先验权限隔离，再验功能完整性。
- 先验数据正确性，再验页面表现。

## 2. 登录与权限

- [ ] 默认系统管理员 `admin` 可在数据库初始化完成后使用初始化密码正常登录。
- [ ] 默认系统管理员登录成功后会更新最后登录时间。
- [ ] 系统管理员可修改本人密码。
- [ ] 业务管理员可使用手机号 + 密码登录。
- [ ] 业务管理员登录成功后会更新最后登录时间。
- [ ] 业务管理员可修改本人密码。
- [ ] 业务管理员首次登录不强制改密。
- [ ] 所有登录均基于数据库用户表认证，不允许回退到内存账号。
- [ ] 未登录访问受保护页面时会被拦截到登录页。
- [ ] 系统管理员可见 `用户管理`、`系统字典`、`操作日志` 等应有菜单。
- [ ] 业务管理员不可见 `用户管理`。
- [ ] 业务管理员不可维护系统字典。
- [ ] 系统管理员不可直接维护充电站、充电桩、股东、持股关系业务数据。

## 3. 用户管理

- [ ] 系统管理员可新增业务管理员。
- [ ] 新增业务管理员时手机号作为登录账号。
- [ ] 手机号格式校验正确。
- [ ] 系统可避免重复手机号账号。
- [ ] 系统管理员可重置业务管理员密码。
- [ ] 重置密码时需手动输入 `6-20` 位且同时包含字母和数字的新密码。
- [ ] 系统管理员可启用业务管理员。
- [ ] 系统管理员可停用业务管理员。
- [ ] 停用后的业务管理员无法继续登录。
- [ ] 业务管理员列表可展示最后登录时间。
- [ ] 用户管理相关操作被记录到日志中心。

## 4. 系统字典

- [ ] 系统管理员可进入系统字典页面。
- [ ] 系统字典第一阶段至少包含：平台、充电站状态、充电桩状态。
- [ ] 系统管理员可新增平台字典项。
- [ ] 系统管理员可修改平台字典项。
- [ ] 系统管理员可启用 / 停用平台字典项。
- [ ] 系统管理员可新增充电站状态字典项。
- [ ] 系统管理员可新增充电桩状态字典项。
- [ ] 系统字典列表可正常展示名称、编码、状态、排序。
- [ ] 充电站表单中的“所在平台”来自系统字典中的平台类型。
- [ ] 第一阶段系统字典页面不出现 API 地址、AppId、密钥等字段。
- [ ] 系统字典维护操作被记录到日志中心。

## 5. 首页概览

- [ ] 首页展示充电站总数。
- [ ] 首页展示充电站状态统计。
- [ ] 首页展示充电桩总数。
- [ ] 首页展示充电桩状态统计。
- [ ] 首页展示股东总数。
- [ ] 首页展示最近操作记录。
- [ ] 首页存在快捷入口：新增充电站、股东管理、操作日志、系统字典。

## 6. 充电站管理

- [ ] 可新增充电站。
- [ ] 新增充电站时系统自动生成全局唯一系统ID。
- [ ] 新增充电站默认状态为 `签合同`。
- [ ] 可编辑充电站名称、平台、地址、联系人等信息。
- [ ] 列表页支持按名称搜索。
- [ ] 列表页支持按平台筛选。
- [ ] 列表页支持按状态筛选。
- [ ] 列表页支持分页浏览。
- [ ] 点击记录可进入充电站详情页。
- [ ] 详情页采用单页分区，不是标签页结构。
- [ ] 详情页包含基础信息、充电桩管理、股东信息、历史变化时间线。
- [ ] 充电站状态可在 `签合同 / 建设中 / 运营中 / 运营异常 / 停用` 之间切换。
- [ ] 状态切换允许任意切换。
- [ ] 状态变更原因备注为可选。
- [ ] 充电站不提供物理删除能力。

## 7. 充电桩管理

- [ ] 可在充电站详情页新增充电桩。
- [ ] 新增充电桩时系统自动生成全局唯一桩编号。
- [ ] 充电桩可录入快充 / 慢充类型。
- [ ] 充电桩可录入充电枪数量。
- [ ] 新增充电桩默认状态为 `运营中`。
- [ ] 可编辑充电桩信息。
- [ ] 充电桩状态可在 `运营中 / 运营异常 / 停用` 之间切换。
- [ ] 状态切换允许任意切换。
- [ ] 状态变更原因备注为可选。
- [ ] 充电桩不提供物理删除能力。

## 8. 股东主档管理

- [ ] 存在独立的股东管理菜单。
- [ ] 可新增股东主档。
- [ ] 可编辑股东主档名称、联系人、联系电话。
- [ ] 股东主档状态只有 `启用 / 停用`。
- [ ] 股东主档不存在“退股”状态。
- [ ] 同一股东主档可被多个充电站复用。
- [ ] 修改股东主档信息后，关联站点展示同步更新。
- [ ] 停用股东后不能继续新增新的持股关系。

## 9. 持股关系与股权调整

- [ ] 可在充电站详情页为站点关联已有股东。
- [ ] 可创建该站点与股东的持股关系。
- [ ] 持股关系状态为 `持股中 / 已退出`。
- [ ] 退股发生在持股关系层，不影响股东主档状态。
- [ ] 同一充电站下所有 `持股中` 股东占比总和必须等于 `100%`。
- [ ] 当某股东退股时，系统要求同步调整其他股东占比。
- [ ] 站点详情页存在“股权调整”入口。
- [ ] 点击后进入独立的股权调整页面。
- [ ] 独立页面可一次性调整多个股东占比。
- [ ] 保存前系统校验占比总和。
- [ ] 股权调整默认立即生效。
- [ ] 股权调整成功后生成一条股权调整事件。

## 10. 时间线与日志

- [ ] 充电站详情页可查看该站历史变化时间线。
- [ ] 股东详情页可查看该股东历史变化时间线。
- [ ] 股东详情页时间线默认展示所有关联站点事件。
- [ ] 股东详情页时间线支持按充电站筛选。
- [ ] 全局存在独立的操作日志页面。
- [ ] 系统管理员可查看全局日志。
- [ ] 业务管理员可查看全局日志。
- [ ] 日志页支持按时间筛选。
- [ ] 日志页支持按操作人筛选。
- [ ] 日志页支持按对象类型筛选。
- [ ] 日志页支持按充电站筛选。
- [ ] 日志详情可查看修改前内容与修改后内容。

## 11. 日志覆盖项

- [ ] 充电站新增会记录日志。
- [ ] 充电站修改会记录日志。
- [ ] 充电站状态变更会记录日志。
- [ ] 充电桩新增会记录日志。
- [ ] 充电桩修改会记录日志。
- [ ] 充电桩状态变更会记录日志。
- [ ] 股东主档新增会记录日志。
- [ ] 股东主档修改会记录日志。
- [ ] 股东主档状态变更会记录日志。
- [ ] 持股关系新增会记录日志。
- [ ] 持股关系退出会记录日志。
- [ ] 股权调整会记录日志。
- [ ] 平台新增与修改会记录日志。
- [ ] 业务管理员新增会记录日志。
- [ ] 业务管理员重置密码会记录日志。
- [ ] 业务管理员启用 / 停用会记录日志。

## 12. 手机端适配

- [ ] 登录页在手机端可正常输入与提交。
- [ ] 首页在手机端可正常浏览统计卡片。
- [ ] 充电站列表在手机端可查询和进入详情。
- [ ] 充电站详情在手机端可顺畅滚动各分区。
- [ ] 充电桩新增与编辑在手机端可正常操作。
- [ ] 股东新增与编辑在手机端可正常操作。
- [ ] 股权调整页在手机端可完成核心编辑流程。
- [ ] 关键按钮、输入框、选择器在手机端不会出现明显遮挡和无法点击问题。

## 13. 数据正确性

- [ ] 充电站系统ID全局唯一。
- [ ] 同一平台下平台ID唯一。
- [ ] 充电桩编号全局唯一。
- [ ] 持股关系占比计算准确。
- [ ] 退股后的关系状态正确。
- [ ] 历史时间线顺序正确。
- [ ] 日志中的操作账号、角色、时间、对象类型正确。

## 14. 上线前检查

- [ ] 数据库初始化脚本准备完成。
- [ ] 默认管理员初始化逻辑完成。
- [ ] 生产环境配置与开发环境配置已区分。
- [ ] 密码加密策略已确认。
- [ ] 接口鉴权策略已确认。
- [ ] 核心功能完成联调验证。
- [ ] 核心日志可追溯。
- [ ] 手机端主流程已验证。
