## 已知兼容性问题

### 低优先级问题

1. **Safari < 13.1**: 不支持 Optional Chaining (`?.`) 和 Nullish Coalescing (`??`)
   - **影响**: 无法在旧版 Safari 上运行
   - **解决方案**: 项目明确要求 Safari 13.1+，符合现代企业应用标准
   - **状态**: 预期行为，无需修复

2. **Firefox < 103**: backdrop-filter 需要手动启用
   - **影响**: 早期 Firefox 版本无模糊效果
   - **解决方案**: 推荐使用 Firefox 103+
   - **状态**: 预期行为，无需修复

3. **IE 11**: 完全不支持
   - **影响**: 无法在 IE 11 运行
   - **解决方案**: Vue 3 和 Vite 不支持 IE 11，项目明确放弃支持
   - **状态**: 预期行为，设计决策

## 自动化构建配置

### Vite 浏览器目标

当前构建配置使用 Vite 默认目标，支持所有现代浏览器。

**建议优化**（可选）:

在 `vite.config.ts` 中明确指定浏览器目标：

```typescript
export default defineConfig({
  build: {
    target: ['chrome80', 'edge80', 'firefox103', 'safari13.1'],
  },
})
```

这将确保构建产物：
- 包含必要的 polyfills
- 优化代码大小
- 保证兼容性

### CSS 前缀自动添加

Vite 内置 PostCSS + Autoprefixer，自动为以下特性添加浏览器前缀：
- `-webkit-backdrop-filter` (Safari)
- `-webkit-box-shadow` (旧版浏览器)
- `-moz-` 前缀 (Firefox 特定特性)

**验证**: 构建后检查 `dist/assets/*.css` 确认前缀已添加。

## 后续建议

### 1. 持续监控

建议在生产环境配置浏览器监控：
- 使用 Sentry 或类似工具收集浏览器兼容性错误
- 监控不同浏览器的使用占比
- 及时发现和修复新的兼容性问题

### 2. 自动化测试

建议集成 Playwright 进行跨浏览器自动化测试：
```bash
npm install -D @playwright/test
npx playwright install
```

可在 CI/CD 中自动运行跨浏览器测试。

### 3. 渐进增强

对于非关键的视觉效果（如 backdrop-filter），可采用渐进增强策略：
```css
.overlay {
  background: rgba(6, 10, 16, 0.9); /* 回退方案 */
}

@supports (backdrop-filter: blur(6px)) {
  .overlay {
    background: rgba(6, 10, 16, 0.72);
    backdrop-filter: blur(6px);
  }
}
```

### 4. 浏览器版本提示

建议在应用中添加浏览器版本检测，当检测到不支持的旧版本时显示升级提示。
